The implementation will generate a simple sourced climate-risk/cost report and plan-discovery summary here, with intentional public copies under `site/literature/`. The preferred deliverables are accessible HTML and CSV; add a simple PDF for the requested downloadable literature report using the PDF skill's render-and-verify workflow. Do not run full scanner packet production.

The risk report must include per-Tribe top available hazards up to five, regional and national summaries, metric definitions, missing-data counts, costs with non-overlapping scope, scanner package version and snapshot/formula versions, generation date and citations. Required disclaimer: **These are pre-generated outputs from the mid-development TCR policy scanner. Use with caution. Coverage, methods and estimates are incomplete and subject to revision; confirm source evidence before making decisions.**

The plan report must state that it inventories publicly discoverable documents. A missing match does not establish that a Tribe has no plan. Include the search window, Nations searched, unresolved candidates, blocked sources and missing dates. Preserve links and metadata for later discovery and access without copying full third-party documents into this repository.

The TSDF download must retain the exact **v0.9.8** label. The owner states that v1.0 was authorized by ATNI Resolution 26-34, the language is unchanged, and the v1.0 website copy is forthcoming. Preserve that distinction until the official v1.0 publication can be verified. Retain the framework's actual license and source attribution.
