## Purpose and audience

Build a GitHub Pages site that works as a facilitated presentation and a participant resource. Explain the National Congress of American Indians Climate Action Task Force mission, the strategic planning process, current progress, public evidence about risks and planning needs, and tools that participants can explore immediately. The audience is Tribal Nations, NCAI and ATNI, which charged this strategic planning work.

The central mission functions are **Document, Inform, Support, Advocate**. Connect each assessment and tool to those functions. Explain that the applications are built by Tribal members for Tribes, help address cost/capacity/usability constraints, and augment existing Tribal institutions. Emphasize sovereign governance, coordinated planning, resource sharing and responses to accelerating climate pressures and interacting crises.

palette paragraph is retained as preparation history, not the active design.

Use `I:\atni-design-system` as the typography, spacing, layout and mark authority. Its maintained tokens and fonts are usable; unfinished web templates are not a prerequisite. League Spartan Medium/SemiBold provides display hierarchy, Noto Sans body copy, and Noto Sans Mono compact numeric labels where useful. Self-host selected font files with their OFL notices.

NCAI/CATF chapters use a new palette inspired by Image #2: warm cream, soft peach, dusty rose, pale sage and muted stone. These are art-directed hues, not an official NCAI brand palette. Use a deep charcoal/green foreground for readable text and accessible interactive accents. Reserve the pale tones for backgrounds and decoration. The reference palm image suggests atmosphere; do not make it the site's repeated visual identity.

ATNI tool chapters switch to the design system's ATNI Climate palette, including red `#E13D33`, accessible small-text red `#B02821`, ink `#010B13`, white and light surfaces. Preserve scientific hazard color conventions. Use a shared type scale, grid, spacing and navigation across both sections so the palette change marks a narrative transition.

Favor generous full-width composition, large legible headlines, short claims and well-labeled visuals. Put methods and caveats in accessible expandable detail while keeping the essential caution visible beside figures. Avoid a dashboard of identical cards, ornamental maps, dense text walls and tiny chart labels. Use accessible HTML/SVG instead of screenshots of text. On phones, participant mode becomes a readable vertical chapter sequence.
